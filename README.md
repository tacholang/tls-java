# 🧊 tls-java

An implementation of a [Tacholang Script (*.tls)](https://spec.tacholang.strokkur.net/spec/syntax-reference/#tacholang-script-tls)
file parser and evaluator written in Java in the style of a general-purpose library.

>[!note]
>This is an incomplete work-in-progress implementation. It may be missing important features or
>outright contain bugs.
